# Course brief

*Type freely. Anything you leave out, the skill either derives or asks for — batched, not one
question at a time. Do not try to fill in the module split, screen counts, task codes or pass
marks: those are derived, and deriving them is the skill's job.*

---

## The one thing without which nothing can start

**Which approved programme governs this course?**
Name it, or give the path. The skill reads the academic-hour length, the topic/hours table and
the ILOs out of it. Without it there is no hours law and no ILOs.

> e.g. `source_files/Programmes/<the approved programme>.pdf` — the original document, not a
> knowledge-base copy of it: an extraction can lose a row of the hours table.

---

## The sources

**Where is the knowledge base?** The folder the Course Source Processor made (it has
`SOURCE_MANIFEST.json` and a `sources` folder), or an older docling one. The factory finds it if it
is in the course folder.

**Is there an old version of this course?** A folder on this computer is best. A Google Drive link
works only if it can be read; otherwise the factory asks you to download it.

**Who is the course for?** New entrants (no prior knowledge) or experienced seafarers (upgrade,
advanced, revalidation). The factory proposes one from the programme; you confirm it.

**Any IMO model course that applies?** It is guidance — the approved programme still governs.
Name it and it will be cited as support.
