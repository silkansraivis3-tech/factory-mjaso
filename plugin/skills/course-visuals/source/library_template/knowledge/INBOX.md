# Inbox - new facts, terms and regulations waiting for review

Added by course sessions with `python tools/contribute.py fact|term|regulation ...`. Nothing here is
settled: **NEW** = not reviewed. The reviewers (`library_config.json` "reviewers") check the source,
then move the row into `FACTS.md` / `GLOSSARY.md` / `REGULATIONS.md` and set ACCEPTED, or set REJECTED
with the reason. Never quote a NEW row on a slide without checking its source yourself. A row about a
CONFLICT subject waits for `OPEN_DECISIONS.md`.
