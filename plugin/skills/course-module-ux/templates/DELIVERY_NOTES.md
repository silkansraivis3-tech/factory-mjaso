## 2 · Honesty markers left in the artefact

Every marker written into any file must appear here. All four, spelled exactly this way.

| Marker | Where (file · screen) | What it is waiting on |
|---|---|---|
| `UNKNOWN` | | asked, the operator did not know — record that it was asked |
| `PLACEHOLDER` | | structure is right, real content missing |
| `PROVISIONAL` | | content exists, depends on something unapproved |
| `[VERIFY: <what to check>]` | | asserted from a source that could not be confirmed |

If a row is empty, write **none** rather than deleting the row — an empty table and a deleted
table read differently to the next person.

Nothing regulatory, no quoted criterion, no set point and no QR code was invented. If any of
those had to be guessed, it is a `[VERIFY: ...]` above, not a fact on the page.
