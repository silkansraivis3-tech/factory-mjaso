Template Blueprints

Every slide and task screen the factory builds, empty: only where each part goes and what fills it. The words come from the approved content script, the pictures from the build sheet. Made from plugin/skills/course-module-ui/knowledge/blueprints.json by scripts/blueprints.py - edit the file, not this page.

TitleTextInfoPictureAnimation3D
  • Title - the screen's title or question - script title / question
  • Text - approved words that teach - script text and the template's own fields
  • Info - what the room reads at a glance - chips, numbers, a table, readings, a list to tick, the choices' marks
  • Picture - a photograph or a static 3D render - build sheet figure; never a flat line drawing (L67)
  • Animation - something that moves by itself - a simulator screen, a clock, a meter, a flow
  • 3D - a live 3D scene the room turns - build sheet figure (*.kit3d.json)
