# Slide templates - the reference deck (2.88.0)

The upgraded slide templates the owner approved on 2026-11-03 (L67), as 28 live slides of one demo module (IGF ships,
module 1). Open `presentation/index.html` in a browser, press Start, then Next (or the arrow keys).

Everything here is built from the factory's own files: `course-module-ui/templates/gb_layouts.css` + `gb_upgrade.css`,
`course-module-ux/assets/gb_steps.js` and `gb_deck.js`, `course-visuals/scene/gb_scene.js` with the reference scenes
`course-visuals/scene/examples/m01_scenes.js`, and the 3D kit. The static 3D pictures in `assets/img/s3d_*.jpg` are
renders of the same scenes.

The words are the demo module's sample copy; the summary questions, drill prompts and the self-check list are sample
text, never approved course words.
