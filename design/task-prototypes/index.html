Bloom Task Lab

Twelve task types for the trainee tablets. Each one is a working prototype, four of them in 3D. Demo content is about LPG cargo, but every type takes any course's content.

One task set, after each teaching block
≈5 min theory→Part A · Check→Part B · Find it yourself→Debrief
Part A checks everything taught so far in the module (2–4 min). Part B gives one harder problem the trainee solves with the tools on screen (4–8 min).
Demo content. Facts are to be checked against the course KB.
