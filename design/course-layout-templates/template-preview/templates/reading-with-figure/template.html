12 / KEEP THE VISUAL IN VIEW

Read the explanation. Keep the connection.

Keep the diagram in view while reading. It provides a visual anchor for the explanation, so the reader can locate each element without remembering an image from an earlier screen.

Introduce the main elements before describing their relationships. Use the same names in the text and legend. Refer to the element itself rather than its position on the screen, especially when the photograph shows a different view.

Bring the individual points back together. Check that the explanation still matches the complete picture.

Additional context can explain an unfamiliar term, describe another example or connect this topic to an earlier lesson. Keep the wording visible at the same reading size when checking whether the chosen layout still has enough space.
